AI API costs add up fast. If you're building agents, automation workflows, or AI-powered features, your API bill can easily become your biggest expense. Here's how to keep it under control.

## Understand per-token pricing

Every AI model charges per token — roughly 0.75 words per token. Pricing is quoted as $/1M tokens, split into input (prompt) and output (completion) rates.

For example, GPT-5.4 charges $2.50/1M input and $10.00/1M output at the official provider. A request with 10,000 input tokens and 2,000 output tokens costs:

```bash
Input:  (10,000 / 1,000,000) × $2.50 = $0.025
Output: (2,000 / 1,000,000) × $10.00 = $0.020
Total:  $0.045
```

## Pick the right model for the job

Not every task needs the most expensive model. Use cheap models for high-volume, low-complexity work:

- **DeepSeek V4 Flash** ($0.03/1M) — classification, extraction, simple Q&A
- **GLM-5.2** ($0.22/1M) — general chat, code generation, reasoning
- **GPT-5.4** ($1.00/1M) — complex reasoning, tool use
- **Claude Opus 4.7** ($3.95/1M) — highest quality, long-context analysis

## Set spend limits

The #1 way to prevent cost overruns is **hard spend limits per API key**. Set a daily cap that matches your budget. If a key hits the cap, it stops — no runaway bills.

Ruvicode supports per-key daily, monthly, and total spend limits out of the box. OpenRouter doesn't offer this at all.

## Use streaming

Streaming responses let you start processing output before the full response is generated. This doesn't save money directly, but it lets you implement early-exit logic — stop the stream as soon as you have what you need.
